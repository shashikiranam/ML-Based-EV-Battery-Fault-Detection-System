# Dataset Description

## Raw Datasets

The project uses experimental battery temperature datasets collected under two operating conditions:

### Load Condition
- T1_Load.xlsx
- T2_Load.xlsx
- T3_Load.xlsx

### No-Load Condition
- T1_No_Load.xlsx
- T2_No_Load.xlsx
- T3_No_Load.xlsx

The datasets contain battery temperature measurements collected from three sensor locations (T1, T2, and T3) under load and no-load operating conditions. These datasets are used for machine learning model training, validation, and battery fault detection.
